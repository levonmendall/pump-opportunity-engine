# Required evidence versus optional diagnostics —239a source audit

No new runtime changes here; this is a call-site classification review, not a measured per-kind production census. Current public telemetry measures aggregate bytes/refusals; it cannot identify which bodies dominate. Preserve that limitation.

## Required, lossless, current proof/financial contract

- Financial ledger/actions/accounting/history and essential quote/cost/order/attempt/position/protection/recovery records. Existing immutable protected proof copies and actual source/strategy/input provenance remain protected.
- `native-flow-validated-events`: every selected successful transaction's compact exact event bytes, signature/program/log index/frame identity/amount conventions/actual receipt+availability, including protocol effects and executed nontrade identities needed for completeness.
- `native-flow-information-available` and cross-scope equivalents: final admission availability, identity and actual admitted count; these differ from earlier parsedAt. Preserve correction/rebound/refusal/gap identities and affected scopes. Never silently omit unsupported selected successful events.
- `native-flow-history-page`: complete independent history rows/actual request bounds and timestamps; `native-flow-audit-post-snapshot-tail`: the actual bound generation/tail facts. Keep audit decisions/certificates/features/failures/deadlines and current support/Clock provenance used by qualification.
- Canonical migration origin proof and verified chain time, discovery identities needed for the observed-universe denominator, watch admission/promotions/re-promotions/technical exclusions, source interruption/recovery boundaries. These are opportunity-accountability facts even though not buying-pressure evidence.
- `research-clock-pool-state` and derived current support/actual-size quotes used by financial actions. No cached reserves, renamed timestamps, or unsupported source assertions.

`essential=false` does NOT mean optional: the current rolling diagnostic namespace contains required raw qualification inputs until `pinRange` durably protects them.

## Safely optional to trading completeness (with explicit omission accounting)

Start with a narrow allowlist, default unknown kinds to required:

- `native-flow-raw-representative` with supplementaryOnly=true. Complete selected compact executed events remain retained independently.
- Additional representative raw refusal stacks after the mandatory offending signature/reason/scope/window invalidation is retained. Preserve bounded first examples for unfamiliar decoder variants where practical; do not erase existing adverse artifacts.
- Repeated `native-paper-local-phase` debug spans, repeated unchanged service-selection/debug snapshots, and redundant usage summaries. Preserve material overruns/incidents and actual financial protection metrics. If omitted, do not claim complete scheduler-trace coverage.
- Intermediate `native-audit-dispatch-state` detail can be optional only while final bounded dispatch summaries/physical start+settlement/accounting and actual deadline outcomes remain retained. Existing16-state coalescing is already implemented, not a new saving.
- Repeated unaudited `native-candidate-feature-view` copies can be coalesced while lossless raw events and actual audited predictive feature assessments/availability remain retained. Never count an omitted/unverified view as a complete assessment.
- High-frequency unverified watch-activity debug hints can be coalesced into actual latest activity/current watch state and bounded counts; retain promotion triggers/reasons and disclose resulting limitations on historical re-promotion/independent-universe audit.

Repeated full `native-origin-import` bodies are a possible larger saving ONLY once the exact original canonical proof has a durable verified content reference. Do not replace them with an unverified hash or mutable checkpoint filename merely to reduce storage.

## Required semantic correction if optional omission is allowed

Simply not setting serviceEvidenceHealthy=false is insufficient. Current recorder refusalIntervals mark EVERY refused timestamp; pinRange rejects a qualification interval touching any of them. Optional capacity omission must have its own bounded counters/coverage markers and must NOT contaminate required-evidence refusal intervals or force source quarantine. True filesystem/integrity failures still affect both classes and fail closed. This can use the existing two physical roles and per-call required/optional purpose; no third portfolio/reporting/control framework is necessary.

For actual required-record refusal, scope the invalidation using the existing NativeFlow.onGap/retire mechanism wherever the affected mint/scopes are known. Preserve holdings and independent discovery/watch and unaffected candidate capture when their evidence remains available. A failed shared prerequisite/unknown affected scope legitimately requires a broader gap; never manufacture completeness.

## Resource policy under the new authorization

The proven proactive watermark repair is necessary even with more disk, because maintenance-after-hard-pressure currently tears down mature valid windows. The128MiB quantity itself is an internal rolling allocation, not a provider entitlement or genuine disk crisis on a host with~269GB free.

A defensible required-raw rolling allocation should derive from measured encoded required bytes/second over the complete60s window + alignment + original audit deadline + bounded retention/pin handoff, with measured burst/I/O runway, constrained by actual free disk after financial/backup/protected-proof reserves. Optional diagnostics should yield first. Keep payload/queue/memory/CPU/provider bounds and honest capacity exclusions; do not allocate all available disk or invent a denominator.

Do not use wall timestamps alone to age old files across restart. Same-boot durable system-monotonic age witnesses can prevent artificial300s rejuvenation; missing/legacy/different-boot evidence needs conservative fallback. Protected financial/qualification data and unresolved obligations are never diagnostic-evicted.
