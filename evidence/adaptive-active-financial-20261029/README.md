Unknown volatility/continuation remains unknown and uses the explicitly declared protective trailing fallback.
- During missing USD, a strictly higher valid SOL peak can be persisted by the same ledger writer without fabricating USD reconciliation or granting entries. Missing/stale/wrong-size input remains data unavailability. Cash, daily-loss controls and financial gates remain intact.

Legacy fill time is a conservative earlier-window cutoff, not an invented historical signal timestamp. Optional proof cache is invalidated on every actual fill. Unknown history grants no reentry.
